# Ursa Compass

UI components for Ursa Compass

## Deprecation notice

Ursa Compass was intended to be an AI agent that could either run on local workstations or within Ursa Studio. The local version of an AI agent has since been reinvented; it's called Claude Code and it's great! Meanwhile, the version that lives inside Ursa Studio has moved fully into Ursa Studio, and is also great! As a consequence, this package no longer needs to be maintained.
